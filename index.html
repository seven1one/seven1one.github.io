Why ECR

Amazon ECR

EKS와 동일 AWS 계정에서 IAM으로 인증하므로 자격 증명 관리가 불필요합니다. VPC 엔드포인트로 이미지 풀을 퍼블릭 인터넷 없이 처리합니다.

Why GitOps

ArgoCD GitOps

kubectl 직접 실행은 관리하기 어렵고 추적하기 어렵습니다. Git 이력이 배포 이력이 되고, 롤백은 revert commit 하나로 끝납니다.

Why 분리

Helm 차트 독립

FE 정적 파일만 바뀌어도 BE 파드가 재시작되는 낭비를 막습니다. 독립 배포 = 독립 롤백이 가능합니다.

Infrastructure

인프라 설계 결정

Terraform 모듈화 vpc / compute / security / storage / sg 계층 분리.
모듈 단위로 terraform apply가 가능해 변경 영향 범위를 제어합니다. 개발 초기엔 EKS만 켜고 RDS는 docker-compose로 대체해 비용을 줄였습니다.
EKS Private 배치 워커 노드는 Private Subnet에만 배치, 외부 노출은 ALB / NLB만.
노드 IP가 공개되면 직접 공격 벡터가 생깁니다. ALB로 네트워크 경계를 단일화해 공격 면을 줄였습니다.
Teleport 4계층 HA NLB(Public) → Proxy x2(Private) → Internal NLB(Private) → Auth x2(Private) 4계층 분리.
Proxy와 Auth 사이에 Internal NLB를 두어 Auth 이중화 트래픽을 분산합니다. Auth 상태는 DynamoDB + S3에 외부화해 Proxy 재시작에도 세션이 유지됩니다.
cert-manager TLS 인증서를 cert-manager가 자동 발급·갱신.
인증서 만료로 인한 장애를 운영자 개입 없이 방지합니다.
관측성 스택 Alloy → Loki (로그), Prometheus + Grafana (메트릭) 분리 수집.
k6 부하테스트 중 Grafana 대시보드에서 병목 구간을 실시간 확인했습니다. 외부 SaaS 없이 클러스터 내부에서 자기 완결적 관측성을 구현했습니다.

AI Assist

GPT-4o가 요청 내용을 분석해 최소 권한 YAML 초안을 제안합니다. Approver 검토·수정 없이는 절대 적용되지 않는 Human-in-the-loop 구조로, AI는 초안 제안 보조 역할만 담당합니다.

Auto Expiry

60초마다 만료 Grant를 감지해 Teleport role과 K8s RBAC을 동시에 삭제합니다. Teleport TTL에만 의존하면 K8s RBAC 오브젝트가 잔존하는 문제를 원천 차단합니다.

Audit Log

모든 요청·승인·프로비저닝 이벤트를 DB에 기록합니다. 누가 언제 어떤 권한을 얼마 동안 사용했는지 추적 가능하도록 설계했습니다.
